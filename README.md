## Descripción
En esta asignatura los estudiantes desarrolaran habilidades para el sieño y construccion de aplicaciones webs
el enfoque de la materia está basado en:

- Desarrolo practica de software
- Construcción progresiva de aplicaicones reales
- Trabajo colaborativo
- Resolucion de problemas

  
## Objetivos de la asignatura
al finalizar el curso el estudiante será capaz de:
- Crear interfaces funcionales
- Aplicar Logica mediante Java Script
- Diseñar Interfaces personales
